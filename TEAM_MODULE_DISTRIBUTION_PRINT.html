1. Architecture Summary

  • Frontend: React + TypeScript in client.
  • Backend: Express + TypeScript in server.
  • Database: Supabase Postgres with RLS policies.
  • Shared logic: shared folder for API types and recommendation engines.
  • Data operations: database SQL scripts, supabase migrations, and scripts imports/fixes.

2. Seeker Module Ownership (Dipesh + Manthan)

Primary files

  • Pages: client/pages/Warehouses.tsx, WarehouseDetail.tsx, SeekerHub.tsx, SeekerBookingsPage.tsx, Saved.tsx, Compare.tsx, SmartBooking.tsx.
  • Components: GridBlockSelector.tsx, BlockGridCSS3D.tsx, BookingSummary.tsx, BookingSummary3D.tsx, InquiryModal.tsx, ScheduleVisitModal.tsx.
  • Services/Hooks: client/services/warehouseService.ts, blockBookingService.ts, smartBookingService.ts, aiService.ts, client/hooks/use-recommendations.ts.
  • Backend routes: server/routes/bookings.ts, simple-booking.ts, saved.ts, activity.ts, schedule-visit.ts, smartBooking.ts.
What this module does: seeker discovery, details, booking initiation, booking history, saved interactions, and recommendation-assisted decisions.

3. Admin Module Ownership (Pranjal)

Primary files

  • Pages: client/pages/AdminDashboard.tsx, AdminBookingsPage.tsx, AdminWarehousesPage.tsx, AdminWarehouseSubmissionsPage.tsx, AdminUsersPage.tsx, AdminVerificationPage.tsx, AdminAnalyticsPage.tsx.
  • Routes: server/routes/admin-bookings.ts, admin-warehouses.ts, admin-warehouse-submissions.ts, admin-user-activity.ts, analytics.ts, approveSubmission.ts.
  • Routing integration: server/index.ts.
What this module does: platform governance through booking moderation, warehouse review, user-level administration, and performance analytics.

4. Owner + Database + Data Ownership (Sahil)

Primary files

  • Owner pages: client/pages/ListProperty.tsx, OwnerProperties.tsx, OwnerAnalyticsPage.tsx, OwnerNotificationsPage.tsx, OwnerProfilePage.tsx, SubmissionView.tsx.
  • Owner routes: server/routes/owner-bookings.ts, warehouse-submissions.ts, warehouseSubmission.ts, recommend-price.ts, product-pricing.ts, cities.ts.
  • Database: database/*.sql, supabase/migrations/*.sql.
  • Data and setup scripts: scripts/import-all-warehouses.ts, import-via-api.ts, generate-warehouse-sql.ts, setup-database.ts, deploy-database-schema.ts, fix-warehouse-data-quality.js, fix-owner-ids.js, verify-data.js.
  • Supabase clients: server/lib/supabaseClient.ts and client/services/supabaseClient.ts.
What this module does: owner lifecycle management, schema correctness, RLS/policy control, and reliable high-volume data onboarding.

5. Shared Cross-Team Files

  • shared/advanced-llm-service.ts: multi-provider LLM fallback orchestration.
  • shared/advanced-ml-algorithms.ts: recommendation model logic.
  • shared/api.ts: shared API request/response contracts.
  • shared/recommendation.ts: recommendation utility logic.
Governance note: These files should be cross-reviewed by all module leads before release.
