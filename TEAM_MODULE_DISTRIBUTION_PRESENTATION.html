Architecture Summary

Frontend

React + TypeScript pages/components in client for seekers, owners, and admins.

Backend

Express routes in server expose API endpoints and enforce business workflows.

Data Layer

Supabase Postgres + RLS policies, migrations, repair scripts, and import automation.

Main Runtime Flow

  • Frontend triggers API calls under /api.
  • Backend routes process booking, review, analytics, and notifications.
  • Supabase tables (especially activity_logs and warehouses) power occupancy and dashboard metrics.

Delivery Plan and Risk Mitigation

Readiness Checklist

  • Seeker flow validated end-to-end by Dipesh + Manthan.
  • Admin moderation and dashboards validated by Pranjal.
  • Schema, RLS, scripts, and owner workflows validated by Sahil.

Key Risks

  • RLS/policy mismatch can break profile/submission reads.
  • Status transition bugs can desync occupancy/availability.
  • Data import drift can affect analytics quality.

Mitigation

  • Lock ownership and handoff checklist per module.
  • Run pre-demo smoke tests on seeker/admin/owner flows.
  • Keep migration + rollback scripts versioned and reviewed.
